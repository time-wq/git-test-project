# Git Test Project: My First Python UI 🚀

Welcome to my very first repository! This project transitions my workflow from the Arduino IDE to VS Code, Git, and GitHub. It features a simple desktop interface built with Python.

## 🛠️ Features
- **Graphical User Interface (GUI):** Built using Python's native `tkinter` library.
- **Interactive Inputs:** Takes user input and updates the interface in real-time.
- **Git Tracked:** Every step of development is backed up using version control.

## ⚙️ Prerequisites
To run this project locally, you need:
1. **Python 3** installed on your machine.
2. **VS Code** (or any text editor).

## 🚀 How to Run the App
1. Open your terminal in this project folder.
2. Run the script using Python:
   ```bash
   python hello.py
   ```
